# ⚽ Bouncing Ball Animation

## About the Project
This is a simple Bouncing Ball project created using HTML and CSS. The ball moves up and down continuously, creating a bouncing effect through CSS animations.

## Technologies Used
- HTML
- CSS

## Features
- Smooth bouncing animation
- Simple and colourful design
- Continuous ball movement

## What I Learned
- CSS animations
- Keyframes
- Transform and positioning
- Animation timing and movement

## Conclusion
This project helped me explore CSS animations and understand how simple styling techniques can bring movement to a webpage.
